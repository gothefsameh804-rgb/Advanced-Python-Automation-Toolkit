برنامج منظم الملفات

برنامج متقدم لتنظيم وإدارة الملفات بسهولة باستخدام Python وواجهة رسومية حديثة.

عن المشروع

برنامج منظم الملفات هو أداة تم تطويرها باستخدام Python و CustomTkinter و Tkinter و ADB. يهدف البرنامج إلى تسهيل إدارة الملفات وتنظيمها والتعامل مع أجهزة Android من خلال الكمبيوتر.

المميزات

  • 📁 تنظيم وإدارة الملفات
  • 🔍 البحث عن الملفات بسهولة
  • 📱 التعامل مع أجهزة Android
  • 🔌 دعم ADB
  • 🖥️ واجهة رسومية سهلة الاستخدام
  • ⚡ تنفيذ عمليات الملفات بسرعة
  • 🎨 واجهة حديثة باستخدام CustomTkinter
  • 📂 إدارة الملفات بطريقة منظمة
